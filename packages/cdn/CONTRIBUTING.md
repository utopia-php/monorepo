# Contributing

We welcome contributions to `utopia-php/cdn`.

## Getting Started

1. Fork the repository.
2. Create a branch from `main` using this format:

```text
type-issueid-description
```

Example:

```text
feat-123-add-fastly-purge-adapter
```

Common branch types:

- `feat` for new features
- `fix` for bug fixes
- `doc` for documentation changes
- `cicd` for CI changes
- `refactor` for internal code changes

## Pull Requests

Before opening a pull request:

1. Run `composer lint`
2. Run `composer analyse`
3. Run `composer test`

Keep pull requests focused and include a clear description of the change and how it was verified.

## Code of Conduct

Please read and follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Feature Requests

For larger changes or new features, open an issue first so the approach can be discussed before implementation.
